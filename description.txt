============================================================================

NEW FILES CREATED
-----------------
- lib/cloudinary.ts                Cloudinary server-side upload module (base64 data URI, 5 MB limit,
                                   PNG/JPEG/JPG/WEBP/GIF MIME guard, folder support)
- lib/qrcode.ts                    QR generation module (generateQRDataUrl / generateQRSvg /
                                   generateQRBuffer; content encodes `/verify?code=<CODE>` URL;
                                   size clamped [64..1024])

                                   payload via uploadSchema; calls uploadImageFromBase64; returns
                                   { url, publicId, width, height } with 201.

                                   code exists in DB; returns image/png (1y immutable cache) or

--------------------

3. Seed the initial admin account: npm run db:seed
4. Start dev server:               npm run dev
